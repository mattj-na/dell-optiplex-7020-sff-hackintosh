# dell-optiplex-7020-sff-hackintosh
EFI for macOS Sequoia and Tahoe made for DELL Optiplex 7020 SFF

What works:
Headphone Jack, 
2-4 USB 2.O Ports, 
1 USB 3.0 Port, 
GPU Accelleration (With OCLP), 
WI-FI through USB Adapter, 
DisplayPort output (even with HDMI Adapter)

What doesn't work:
All of the other USB Ports, 
Integrated Speaker, 
VGA Video Output (if OCLP Root Patches applied)
